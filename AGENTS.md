# Agent instructions

This file complements [`CLAUDE.md`](CLAUDE.md). Both files apply to work in this
repository.

## Sub-agents

- The only permitted sub-agent is **Luna** (`luna`). Do not spawn, delegate to, or
  accept work from any other sub-agent, model, or agent identity.
- Luna is allowed to do anything in the repository: investigate, edit any file,
  modify shared contracts and configuration, run commands and tests, and work across
  module boundaries. The usual main-agent-only and file-ownership restrictions do not
  limit Luna.
- If Luna is unavailable, continue as the main agent rather than substituting a
  different sub-agent.

All other project conventions, commands, and module boundaries are defined in
`CLAUDE.md` and its linked rules.
